# 走行統計：平均電費・走行距離・走行時間・平均速度

## 更新の操作（既存ユーザー向け）

Porsche ID・パスワード・接続キーを変更する必要はありません。すでに動いているRenderサーバーを更新します。

1. この変更のPull Requestで **Merge pull request → Confirm merge** を押す。
2. GitHubの **Actions** が緑になれば、アプリ画面の更新は完了。
3. **[Renderの管理画面](https://dashboard.render.com/)** を開く。
4. **macan-control-api** を選ぶ。画面の左上寄りに大きく **macan-control-api** と書かれたサーバー画面を開く。
5. その画面の **右上の黒い「Manual Deploy」→「Deploy latest commit」** を押す。
6. サーバー名の下にあるコミット番号の右側が、緑色の **「✓ Live」** になるまで待つ。
7. iPhoneでMacan Controlを開き直す。接続が解除されていれば既存のURL・接続キーで **接続して取得** を押す。接続中なら **今すぐ取得** を押す。
8. **走行統計** の欄に4項目が表示される。**集計の種類** で短期・長期・充電サイクルを切り替える。

走行統計の欄が出ない場合は、ホーム画面アプリと、このアプリを開いているSafariタブをすべて閉じてから、オンラインで開き直す。旧キャッシュの入れ替えに必要な場合がある。

## 表示する値

| 表示 | 単位・意味 |
| --- | --- |
| 平均電費 | 車両のAPIが返すkWh/100km。その下に100÷電費で換算したkm/kWhを表示（正の値のみ） |
| 走行距離 | 選択した集計のkm。総走行距離とは別 |
| 走行時間 | 選択した集計の分 |
| 平均速度 | 選択した集計のkm/h。車両が返した値を表示 |

たとえば20 kWh/100kmは、100km走るのに20kWh使ったという意味で、換算すると5 km/kWh。

短期・長期・充電サイクルは、Porsche側のそれぞれの集計をそのまま表示する。日次・月次とは見なさず、期間同士を合算・平均しない。リセット条件は車両の設定に従う。取得日時と集計データの終了日時を別々に表示し、不明な終了日時を現在日時で補わない。

未対応・欠損項目は **未取得** と表示する。実際に返された0は0として表示する。残量％から電費を推測しない。負の平均消費電力量は返された値を保持し、km/kWhへの換算は行わない。

## 取得できない場合

- **サーバーを更新済みか確認してください**：Render側が以前のコードの可能性がある。上の手順5を実行する。
- **選択した集計の走行統計は、この車両のAPIから取得できませんでした**：Porsche側の応答に有効な集計がない。別の集計を選択する。契約・車両・地域・設定によって取得できない場合がある。
- **走行統計を取得できませんでした。車両情報の取得は継続しています**：統計用の追加通信に失敗・タイムアウト。5分後の取得で再試行する。
- **前回取得した値です**：通信に失敗したため表示を保持している。取得日時を確認する。

本変更は実車での取得を保証するものではない。模擬APIと実際のライブラリのHTTP形式で検証しているが、利用者の車両の応答は更新後に確認する。トークンや生レスポンスをチャットへ送る必要はない。

## 実装仕様

既存の認証付き `/api/snapshot` のschemaVersion 1に、追加の `tripStatistics` フィールドを付加。既存の車両snapshotは互換を維持する。専用の位置取得・車両操作は追加しない。

通常の車両情報取得に続き、同じ車両のGETへ以下だけを要求する。

- `TRIP_STATISTICS_SHORT_TERM` → `shortTerm`
- `TRIP_STATISTICS_LONG_TERM` → `longTerm`
- `TRIP_STATISTICS_CYCLIC` → `sinceCharge`

フィールドは `distanceKm`、`avgKwhPerHundredKm`、`drivingTimeMinutes`、`avgSpeedKmh`、`tripEndTime` を単位に合わせて正規化。曖昧な `value` フィールドや別単位の値を推測して解釈しない。VIN・位置・識別子・上流例外本文を返さず、4指標と時刻だけを許可する。

追加通信は最大6秒かつ既存30秒タイムアウトの余裕内に制限。失敗しても正常な車両snapshotを返す。結果は既存の5分キャッシュに含む。走行統計は接続中の画面メモリに保持し、接続解除で消去。今回のCSV／JSONは従来の車両記録・整備記録が対象で、走行統計の保存・出力は含まない。
